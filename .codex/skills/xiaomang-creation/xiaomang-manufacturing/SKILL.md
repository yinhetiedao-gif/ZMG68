# Xiaomang Manufacturing

## 预检清单

- 单位固定为 mm，确认目标宽/高/厚度和缩放误差。
- 计算最小壁厚、线宽、孔洞和间隙；结合喷嘴直径给出中文警告。
- 清理极短元素、孤岛、重复面和未连接根部；保留原始 clean geometry 供回滚。
- 确认组件策略：单一连通面料才允许默认 STL；多组件必须有用户明确选择并在报告中列出。
- 将质量档、圆润程度、有机融合、平滑迭代写入工作单，防止预览参数与最终参数漂移。

输出 `manufacturing_preflight`。任何硬性约束失败都阻断最终后端导出，不能用“看起来没问题”替代数值检查。
