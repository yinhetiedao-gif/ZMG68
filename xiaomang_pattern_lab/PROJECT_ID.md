# Xiaomang Pattern Lab / 小芒图案实验室

Project Name: Xiaomang Pattern Lab

Chinese Name: 小芒图案实验室

Project Status: ACTIVE

Purpose: Raster / SVG / Editable 2D Pattern / Parametric Design Experimental Platform

Old Xiaomang Application: DEPRECATED

## Default launch rule

When an instruction says “运行软件”、“启动项目” or “测试现在的软件”, it means this project unless the instruction explicitly names the deprecated Xiaomang application.

## Source entry point

`xiaomang_pattern_lab.main` is the active Python entry module. Run it through `run_pattern_lab.ps1` from this directory. The resulting window title must be **小芒图案实验室 / Xiaomang Pattern Lab**; any window titled “小芒造物” is the deprecated application and must be closed.
